# Origem e Estrutura dos Dados

## Dataset: Adventure Works
Os dados utilizados neste projeto foram extraídos do dataset público **Adventure Works**, disponibilizado pela Microsoft. Este banco de dados é amplamente utilizado para demonstrações de Business Intelligence por simular um cenário real de uma empresa multinacional de fabricação e venda de bicicletas e acessórios.

## Contexto do Negócio
A base de dados abrange diversos fluxos operacionais, incluindo:
*   **Vendas (Sales):** Registros de transações online e através de revendedores.
*   **Produtos (Products):** Catálogo detalhado de itens, categorias e subcategorias.
*   **Clientes (Customers):** Informações demográficas e geográficas.
*   **Territórios:** Estrutura global de vendas dividida por regiões.

## Dicionário de Dados e Processamento
Para esta análise de BI, foram priorizadas as tabelas de fatos de vendas e as dimensões de calendário, produtos e clientes. 

As principais transformações realizadas incluíram:
1.  **Limpeza:** Remoção de duplicatas e tratamento de valores nulos em colunas críticas.
2.  **Padronização:** Ajuste de tipos de dados (Datas, Moedas e Textos).
3.  **Modelagem:** Criação de colunas calculadas para segmentação de mercado.

---
*Nota: Este conjunto de dados é fictício e utilizado exclusivamente para fins de demonstração de competências técnicas em análise de dados.*
